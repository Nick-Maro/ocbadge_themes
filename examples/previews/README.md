# Offline theme previews

These SVGs are generated by `gen.py` from [`../sample-player.json`](../sample-player.json).
Every preview uses the fictional `ctf_explorer` account. No live profile, token or
API response is included. Images embed their logo and optional chart and need no
remote assets to render.

From the repository root, after installing `requirements.txt`:

```sh
python gen.py default --sample --output examples/previews/default.svg
python gen.py dark --sample --output examples/previews/dark.svg
python gen.py white --sample --output examples/previews/white.svg
python gen.py darkRed --sample --output examples/previews/darkRed.svg
python gen.py hacker --sample --output examples/previews/hacker.svg
python gen.py oldDefault --sample --output examples/previews/oldDefault.svg
```

Keep the gallery in the main README synchronized when changing a template.
Preserve the repository's [upstream attribution and license-status notice](../../README.md#credits-and-reuse);
these previews do not grant additional rights to inherited templates or assets.
